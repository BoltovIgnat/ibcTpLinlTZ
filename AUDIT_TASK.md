## 2. Обязательные разделы документа

### B.1. Проблемы фильтров

- URL: https://tp-link.ru/catalog/routery-wi-fi/
- Конкретные пункты (не общие фразы «плохо»).
- **2–4 скриншота** с подписями.

Типичные находки (ориентир для анализа):

- дублирующиеся фильтры с разными названиями;
- фильтры без товаров / товары без значений для фильтра;
- устаревшие значения (Wi‑Fi 4/5/6);
- несогласованность с фактическими свойствами карточек.

### B.2. Проблемы характеристик карточек

- **Минимум 5 примеров** с карточками или прямыми ссылками.
- Скриншоты или URL.

Примеры классов проблем:

- пустые обязательные поля;
- одно свойство под разными названиями в разных товарах;
- разные единицы (Mbps vs Гбит/с);
- устаревшие модели с некорректной ценой **0 ₽** (находка для отчёта, не ошибка импортёра A).

### B.3. Унифицированная модель свойств

Таблица **минимум 10 свойств**:

| Свойство (CODE) | Название на сайте | Тип | Обяз. | В фильтре | Источник данных | Комментарий |
|-----------------|-------------------|-----|-------|-----------|-----------------|-------------|
| `WIFI_STANDARD` | Стандарт Wi‑Fi | список | Y | Y | автоимпорт tp-link.com | … |
| … | … | … | … | … | … | … |

**Источник данных** — одно из: `1С:УНФ` / `вручную` / `автоимпорт tp-link.com`.

Согласовать с полями импортёра [MODULE_ASSIGNMENT.md §5.1](./MODULE_ASSIGNMENT.md) и расширить для боевого каталога Aspro.

### B.4. Оценка трудозатрат

Разбивка по этапам (часы):

1. Миграция / нормализация данных в IB.
2. Перенастройка умного фильтра Aspro.
3. Выборочная перепроверка карточек (N шт.).
4. Регрессия SEO / URL.

Реалистичные оценки — не «2 часа всё» и не «300 часов».

### B.6. TP-Link vs Omada (+30 мин)
